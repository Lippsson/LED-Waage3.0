# LED-Wasserwaage 2.0

Die LED-Wasserwaage aus Make 4/25 hat leider einen Bug: Waagerecht funktioniert sie zuverlässig, doch lotrecht zeigt sie konsequent etwa 5 Grad daneben. Diesen Fehler habe ich behoben und die Waage bei der Gelegenheit grundlegend umgebaut. Herausgekommen sind eine zuverlässigere, leichtere Wasserwaage. Hier gibt es den neuen Sketch. Voraussetzung sind einige kleine Änderungen an der Hardware, wie im Artikel beschrieben, damit die LEDs im Deep-Sleep-Modus nicht unnötig viel Strom verbrauchen.
